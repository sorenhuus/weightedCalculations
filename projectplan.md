# Weighted Calculations
Weighted Calculations is an Android app that does weighted calculations.

## Layout
The screen is designed as follows:


|name| x | y | Sum|
|---|---|---|---|
| user input string | user input number | user input number | calculated x*y |
| user input string | user input number | user input number | calculated x*y |
| user input string | user input number | user input number | calculated x*y |
|  |  |  | sum |

## Future phases
In a future phase the application should also be build for IOS.
